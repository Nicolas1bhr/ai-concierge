# Executable Contract Program

[CONCIERGE_FOUNDATION_EXECUTABLE_CONTRACT_PROGRAM_v0.1.md](CONCIERGE_FOUNDATION_EXECUTABLE_CONTRACT_PROGRAM_v0.1.md)
is the bootstrap specification for this repository. It turns the Canon and Foundation into
machine-testable institutional contracts and defines the phased build program with hard gates
(§25, tracked in [ROADMAP.md](../ROADMAP.md)).

Its governing idea: **do not ask whether an implementation resembles the architecture — require the
implementation to prove the properties the architecture demands.**

Subordinate to Canon and Foundation. Pinned in [`PINS.yaml`](../PINS.yaml).
